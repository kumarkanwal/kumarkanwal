## Projects

### Portfolio RAG assistant

A retrieval-augmented assistant that answers questions about my work from my own
documents. It cites the document each answer came from, and refuses rather than
inventing a detail.

- Four model providers in an automatic fallback chain, free tiers first
- Local embeddings, so retrieval has no API dependency or rate limit
- Three layers of spend protection, all checked before any model call

`Python` `FastAPI` `LangChain` `Chroma` `Docker`

[Live](https://kanwalkumar.com/#/#ask) ·
[Source](https://github.com/kumarkanwal/kanwal-kumar-ai-portfolio-rag-aiagent)
